# 📚 Library Management System

A complete Library Management System developed using C++ and Data Structures concepts such as Linked Lists, Stack, Queue, and Binary Search Tree (BST).

The system allows administrators and users to manage books, borrow and return books, search for books, and store data using file handling.

---

# 📌 Features

## 📖 Book Management
- Add new books
- Delete books
- Update book information
- Display all books
- Sort books by ID

---

## 👤 User Management
- Create user accounts
- Login system
- Change password
- Borrow books
- Return books

---

## 🔍 Searching System
- Search books by ID
- Search books by title
- Binary Search Tree (BST) implementation

---

## 💾 File Handling
- Save books to files
- Load books from files
- Save users to files
- Persistent data storage

---

# 🛠️ Data Structures Used

## Linked List
Used for dynamic book storage.

## Stack
Used for recently added books.

## Queue
Used for managing borrowing requests.

## Binary Search Tree (BST)
Used for fast searching operations.
